# Security policy

## Supported versions

The `mixtrapi/1` protocol and the latest release of this repository receive security fixes.

## Reporting a vulnerability

Email jonas.hagmar@protonmail.com. Include the affected protocol area (HTTP, session, workspace, auth) and a way to reproduce.

You will receive an acknowledgement within 7 days. A fix or a reasoned status update follows within 30 days. Do not open a public issue for an unfixed vulnerability.
